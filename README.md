## 1. Цель работы

Изучить основы разработки веб-приложений с использованием FastAPI, научиться создавать API-эндпоинты, работать с моделями данных, параметрами запросов, обработкой ошибок, конфигурацией и логированием.

## 3. Выполнение лабораторной работы

### Задание №1. Создание проекта

Создан проект FastAPI, настроено виртуальное окружение, установлены необходимые зависимости. Инициализирован Git-репозиторий.

### Задание №2. GET и Query

Создан эндпоинт получения товара по ID с использованием параметров пути и строки запроса.

### Задание №3. Модель Item и POST

Создана модель товара Item с полями name, price и is_offer. Реализован POST-эндпоинт для передачи данных товара.

### Задание №4. APIRouter

Маршруты товаров вынесены в отдельный файл app/routers/items.py. Для организации маршрутов использован APIRouter.

### Задание №5. Конфигурация через Pydantic Settings

Создан файл app/config.py. Настройки приложения загружаются из файла .env.

### Задание №6. Обработка ошибок и документация

Добавлена тестовая база товаров, обработка ошибки 404, ограничения параметров через Path и Query, описания и примеры полей через Field. Добавлены метаданные приложения и документация ответов.

### Задание №7. Обновление товаров

Реализован PUT-эндпоинт для обновления товара. Добавлена проверка существования товара и уникальности названия.

### Задание №8. Логирование

Добавлено логирование с использованием стандартной библиотеки logging. Реализованы сообщения INFO и WARNING для отслеживания операций приложения.

## 4. Результаты работы

В результате лабораторной работы создано FastAPI-приложение со следующими возможностями:

- Получение товаров через GET.
- Создание товаров через POST.
- Обновление товаров через PUT.
- Проверка корректности данных.
- Обработка HTTP-ошибок 404 и 409.
- Загрузка настроек из .env.
- Автоматическая документация Swagger.
- Логирование событий приложения.
